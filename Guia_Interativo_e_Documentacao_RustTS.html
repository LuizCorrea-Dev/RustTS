01 · Pilares Arquiteturais, Sintaxe Canônica & CLI

A gramática .rts combina o subconjunto determinístico de Rust e TypeScript sob a regra da Forma Canônica Única: existe apenas uma maneira válida de declarar estruturas, iterar e tratar erros, eliminando ambiguidade semântica para humanos e LLMs.

Zero-Novelty · LL(k)

Estrutura Mínima de Módulo (.rts)

module drone.thermal_control;
import core.hardware;

struct SensorConfig {
    target_temp_celsius: f32,
    max_pwm_duty: u8,
}

enum HardwareFault {
    I2CTimeout(u8),
    SensorDisconnected,
    OverheatCritical(f32),
}

pub fn regulate(
    cfg: SensorConfig,
    i2c: cap I2CBus<0x48>,
    pwm: cap PWMPin<4>
) -> Result<f32, HardwareFault> {
    let raw: u16 = i2c.read_register_u16(0x00)?;
    let mut duty: u8 = 25;
    let temp: f32 = (raw as f32) * 0.0625;
    if temp >= cfg.target_temp_celsius {
        duty = cfg.max_pwm_duty;
    }
    pwm.set_duty(duty);
    return Ok(temp);
}

Comandos & Alvos da CLI (rtsc)

// 1. Criar projeto autônomo (`pub fn main`) e executar com símbolos `#line`
rtsc init meu_projeto
rtsc run examples/kanori_zone_sim/src/main.rts -g

// 2. Validação estática (< 15ms) com resolução multi-arquivo
rtsc check src/main.rts --json-diagnostics

// 3. Gerar C99 SoA/AVX2 + header ABI C/C++ (.h) ou binário com libs externas
rtsc build src/main.rts --out-dir build --emit-header
rtsc build src/main.rts --bin -o build/app.exe -l raylib -L ./lib -I ./include

// 4. Backends Unreal Engine 5 (UHT), Unity C-ABI e TypeScript SDK
rtsc build src/combat.rts --target unreal --out-dir build/unreal
rtsc build src/sim.rts --target unity --out-dir build/unity
rtsc build src/api.rts --emit-ts-sdk -o build/client.ts

// 5. Exportar gramática GBNF para decodificação travada
rtsc --export-gbnf > rustts.gbnf
Restrições Estritas da Gramática

Proibido: null, undefined, ponteiros brutos (*T), try/catch/throw, herança de classes OOP, sobrecarga de operadores e macros procedurais opacas.

03 · Matriz de Capacidades (cap) — Autoridade Ambiental Zero

Nenhuma função acessa hardware, rede, banco SQL, colunas ECS ou arenas sem receber o token linear cap explicitamente em seus parâmetros. Tentar fabricar tokens fora de main dispara RTS-E0404.

Domínio de Segurança

04 · Hierarquia de Arenas ($O(1)$) & Fronteira Tier-0

Em vez de Garbage Collector ou anotação manual de lifetimes ('a), o verificador impõe uma relação matemática de ordem parcial entre escopos de memória: dados de um Rank menor nunca escapam para um Rank maior (RTS-E0501).

Rank 3 · Global Vida Total

StaticArena

Permanece alocada durante todo o ciclo de vida do processo ou firmware. Pode receber dados de qualquer arena de Rank ≥ 3 (apenas estáticos).

Rank 2 · Persistente Entre Quadros

LevelArena · SessionArena · MutColumn<T>

Persiste entre quadros de simulação ou durante a sessão de usuário. Aceita cópias de Rank 2 ou 3, mas bloqueia handles oriundos do Rank 1.

Rank 1 · Efêmera Reset O(1)

FrameArena<T> · RequestArena · TaskArena

Zerada em tempo constante O(1) a cada 16,6 ms (fim do frame) ou ao encerrar a requisição HTTP. Inclui visões ReadFrameArena<T>.

Simulador de Regra de Escape entre Arenas (RTS-E0501)

Fronteira Tier-0: Domínio Web Tradicional Banido (RTS-E0900)

Bloqueado em Compilação

A RustTS rejeita estruturas ou chamadas que modelem DOM tradicional: DOM, DOMNode, Document, HtmlElement, CssStyle, VirtualDom, ReactComponent e WindowDom. Interfaces web devem consumir a API via --emit-ts-sdk.

05 · Controle de Fluxo & Operadores Canônicos

Sem variações sintáticas concorrentes: laços limitados a for .. in a..b e while, ramificação algébrica exaustiva via match e propagação explícita com ?.

Pattern Matching Exaustivo

RTS-E0302 
match fault {
    HardwareFault::I2CTimeout(addr) => {
        return addr;
    },
    HardwareFault::SensorDisconnected => {
        return 1;
    },
    _ => {
        return 255;
    },
}

Aplica-se também a Result<T, E> (Ok(v) / Err(e)) e Option<T> (Some(v) / None). Omissão de braço falha antes da emissão de código.

Iteração Determinística (For & While)

SoA / Strip-Mining 
let count: usize = transforms.len();
for i in 0..count {
    transforms[i].pos = transforms[i].pos
        + (velocities[i].vel * dt.fixed_delta);
}

let mut retries: u8 = 0;
while retries < 3 {
    retries = retries + 1;
}

O backend C99 reconhece laços for i in 0..count sobre colunas MutColumn<T> e emite vetores AVX2/FMA3 com RTS_RESTRICT.

Propagação de Erro (?) & Cast (as)

Zero Exceptions 
let raw: u16 = i2c.read_register_u16(0x00)?;

// Conversão numérica sempre explícita (sem coerção oculta)
let temp_c: f32 = (raw as f32) * 0.0625;

// Condicional canônica
if temp_c >= 105.0 && !override_flag {
    return Err(HardwareFault::OverheatCritical(temp_c));
}
